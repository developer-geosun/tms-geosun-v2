# Справочник видов документов

## Статус
- **Каталог (CRUD):** реализовано (Flyway `V35`, admin UI `/admin/document-types`, доступ `ADMIN`).
- **Seed:** свидетельство о регистрации ТС (UA) — `V36` / `V37` (исправление UTF-8).
- **Интеграция с карточками ТС/водителей:** не реализована (enum `VehicleDocumentType` / `DriverDocumentType` пока не заменены).

## Цель
- Единый **admin-only** справочник видов документов с локализованными названиями (uk / en / ru).
- Привязка вида к **стране** (`country_reference.code_alpha2`).
- Описание **ожидаемого числа страниц скана** и **JSON-полей** `{ key, nameUk, nameEn, nameRu }` для последующего динамического UI.
- Мягкое удаление (`is_deleted`, `deleted_at`).

## Связанные документы
- [`vehicles-reference.md`](vehicles-reference.md) — поля `registration_series` / `registration_number`, сканы свидетельства.
- [`drivers-and-vehicle-combinations.md`](drivers-and-vehicle-combinations.md) — паспорт, права, сканы FRONT/BACK.
- [`file-storage.md`](file-storage.md) — хранение бинарников.
- [`document-ocr.md`](document-ocr.md) — распознавание сканов и предзаполнение `field_definitions` (спека).

## Вне области (текущий этап)
- Замена enum-типов на ссылки из справочника в API ТС/водителей.
- Автоматическая валидация значений полей по regex из справочника (только описание полей).
- Виды документов для юрлиц, договоров, страховок ТС и т.п.

## Модель данных (`document_types`)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | UUID | Первичный ключ |
| `name_uk`, `name_en`, `name_ru` | string(128) | Название вида документа |
| `country_code` | ISO-3166-1 alpha-2 | FK → `country_reference` |
| `planned_scan_pages` | int | Ожидаемое число страниц скана; **0 = не определено** |
| `field_definitions` | JSON array | Список полей документа |
| `is_deleted`, `deleted_at` | bool, datetime | Soft delete |

### Элемент `field_definitions[]`

| Поле | Описание |
|------|----------|
| `key` | Ключ поля в API/UI: `[a-zA-Z][a-zA-Z0-9_]*` |
| `nameUk`, `nameEn`, `nameRu` | Подпись поля для формы |

### Уникальность
- Среди **активных** записей: пара `(country_code, name_uk)` без учёта регистра.

### API
- `GET/POST/PUT/DELETE /api/v1/admin/document-types` — только `ADMIN`.
- Query: `view=active|deleted|all`, `search`, `country`.

## Область применения (логическая, v2)

> В БД отдельная колонка `scope` **пока не добавлена**. Ниже — целевое назначение для интеграции.

| Scope | Описание |
|-------|----------|
| `VEHICLE` | Документ транспортного средства |
| `DRIVER` | Документ водителя (кадровый) |

## Каталог видов документов (UA, v1)

Ниже — нормативное описание **пяти** базовых видов для Украины.  
Формулировки полей согласованы с уже существующими полями карточек ТС/водителя там, где это возможно.

### 1. Свидетельство про реєстрацію ТС

| | |
|---|---|
| **Область** | `VEHICLE` |
| **Страна** | `UA` |
| **Статус seed** | ✅ есть (`id = c1000000-0000-4000-8000-000000000001`) |
| **Плановые страницы скана** | **2** (лицевая / обратная сторона) |
| **Связь с текущей моделью** | `vehicles.registration_series`, `vehicles.registration_number`; endpoint `.../registration-certificate/{front\|back}` |

#### Названия

| uk | en | ru |
|----|----|-----|
| Свідоцтво про реєстрацію | Registration certificate | Свидетельство о регистрации |

#### Поля (`field_definitions`)

| key | nameUk | nameEn | nameRu | Примечание |
|-----|--------|--------|--------|------------|
| `registrationSeries` | Серія свідоцтва | Registration series | Серия свидетельства | Буквенная серия (напр. `СХЕ`) |
| `registrationNumber` | Номер свідоцтва | Registration number | Номер свидетельства | Цифровая часть |

#### Сканы
- Стороны: `FRONT`, `BACK` (как у `vehicle_registration_scans`).
- MIME: `image/jpeg`, `image/png`, `application/pdf`; max 10 MB.

### 2. Посвідчення водія (водительское удостоверение)

| | |
|---|---|
| **Область** | `DRIVER` |
| **Страна** | `UA` |
| **Статус seed** | ⬜ планируется |
| **Плановые страницы скана** | **2** (лицевая с фото / оборот с категориями) |
| **Связь с текущей моделью** | `drivers.license_number`, `license_categories`, `license_expires_on`; enum `DriverDocumentType.DRIVER_LICENSE` |

#### Названия

| uk | en | ru |
|----|----|-----|
| Посвідчення водія | Driver's license | Водительское удостоверение |

#### Поля (`field_definitions`)

| key | nameUk | nameEn | nameRu | Примечание |
|-----|--------|--------|--------|------------|
| `licenseNumber` | Номер посвідчення | License number | Номер удостоверения | Уникален среди активных водителей |
| `licenseCategories` | Категорії | Categories | Категории | Напр. `B, C, CE` |
| `licenseExpiresOn` | Дійсне до | Valid until | Действует до | Дата окончания; ISO date в API |

#### Сканы
- Стороны: `FRONT`, `BACK`.
- На сканах также фиксируются `valid_from` / `valid_to` версии документа (как в `driver_documents` сегодня).
- Compliance: порог «скоро истекает» — 30 дней (как у водителей v1).

### 3. Паспорт громадянина України (національний паспорт)

| | |
|---|---|
| **Область** | `DRIVER` |
| **Страна** | `UA` |
| **Статус seed** | ⬜ планируется |
| **Плановые страницы скана** | **2** (ID-картка: лицева / оборот; **или** разворот книжечного паспорта — 1 физический разворот = 2 страницы) |
| **Связь с текущей моделью** | enum `DriverDocumentType.PASSPORT` (без разделения internal/foreign — **заменить** ссылкой на этот вид при интеграции) |

#### Названия

| uk | en | ru |
|----|----|-----|
| Паспорт громадянина України | Ukrainian citizen passport | Паспорт гражданина Украины |

#### Поля (`field_definitions`)

Поддерживаются **оба** физических носителя; при заполнении используются только релевантные поля.

| key | nameUk | nameEn | nameRu | Примечание |
|-----|--------|--------|--------|------------|
| `documentNumber` | Номер документа | Document number | Номер документа | ID-картка: 9 цифр; книжка: серия+номер в одном поле или см. ниже |
| `passportSeries` | Серія (книжковий) | Series (booklet) | Серия (книжечный) | Только книжечный паспорт, напр. `КМ` |
| `passportNumber` | Номер (книжковий) | Number (booklet) | Номер (книжечный) | Только книжечный паспорт |
| `recordNumber` | Запис № | Record No. | Запись № | ID-картка (номер в реестре) |
| `issuedBy` | Ким виданий | Issued by | Кем выдан | Орган выдачи |
| `issuedOn` | Дата видачі | Issue date | Дата выдачи | ISO date |
| `expiresOn` | Дійсний до | Valid until | Действителен до | ID-картка; для книжки — опционально / пусто |

#### Сканы
- Стороны: `FRONT`, `BACK`.
- `valid_to` для ID-картки обязателен для compliance; для книжечного паспорта срок часто не указан — допускается пустое `expiresOn` при `planned_scan_pages = 2`.

### 4. Закордонний паспорт (заграничный паспорт)

| | |
|---|---|
| **Область** | `DRIVER` |
| **Страна** | `UA` |
| **Статус seed** | ⬜ планируется |
| **Плановые страницы скана** | **2** (стр. с фото + стр. с персональными данными; **0** допустимо, если число страниц варьируется) |
| **Связь с текущей моделью** | новый вид; сегодня не отделён от `PASSPORT` |

#### Названия

| uk | en | ru |
|----|----|-----|
| Закордонний паспорт | International passport | Заграничный паспорт |

#### Поля (`field_definitions`)

| key | nameUk | nameEn | nameRu | Примечание |
|-----|--------|--------|--------|------------|
| `passportNumber` | Номер паспорта | Passport number | Номер паспорта | Биометрический: 2 лат. буквы + 6 цифр |
| `issuedBy` | Ким виданий | Issued by | Кем выдан | Код органа (напр. `8010`) или текст |
| `issuedOn` | Дата видачі | Issue date | Дата выдачи | ISO date |
| `expiresOn` | Дійсний до | Valid until | Действителен до | ISO date; обязателен для compliance |

#### Сканы
- Стороны: `FRONT`, `BACK` (оборот может содержать доп. данные / подпись).
- При интеграции с рейсами за EU — проверка `expiresOn` относительно даты начала рейса.

### 5. ІПН (идентификационный номер налогоплательщика, ИНН)

| | |
|---|---|
| **Область** | `DRIVER` |
| **Страна** | `UA` |
| **Статус seed** | ⬜ планируется |
| **Плановые страницы скана** | **1** (одностраничная справка / выписка / скан карточки с кодом) |
| **Связь с текущей моделью** | новый вид; отдельного поля в карточке водителя пока нет |

#### Названия

| uk | en | ru |
|----|----|-----|
| ІПН | Tax ID (INN) | ИНН |

#### Поля (`field_definitions`)

| key | nameUk | nameEn | nameRu | Примечание |
|-----|--------|--------|--------|------------|
| `innCode` | Код ІПН | INN code | Код ИНН | 10 цифр; контрольная сумма по алгоритму ДПСУ (валидация — v2) |

#### Сканы
- Одна страница: достаточно стороны `FRONT` (или один файл без привязки к BACK).
- MIME: `image/jpeg`, `image/png`, `application/pdf`; max 10 MB.
- Срок действия не применяется (поле `expiresOn` не используется).

## Рекомендуемые UUID для seed (Flyway)

| Вид | `id` |
|-----|------|
| Свидетельство о регистрации ТС | `c1000000-0000-4000-8000-000000000001` |
| Посвідчення водія | `c1000000-0000-4000-8000-000000000002` |
| Паспорт громадянина України | `c1000000-0000-4000-8000-000000000003` |
| Закордонний паспорт | `c1000000-0000-4000-8000-000000000004` |
| ІПН (ИНН) | `c1000000-0000-4000-8000-000000000005` |

> Для seed-миграций кириллицу в SQL сохранять через `CONVERT(UNHEX(...) USING utf8mb4)` (см. `V37`) — иначе на Windows возможна порча кодировки.
